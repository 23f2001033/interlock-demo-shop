# demo-shop

A tiny shop backend in Python 3.11: catalog, cart, pricing (shipping and tax), a fake payment gateway, orders and receipts.

- Run the tests with `uv run pytest -q`. They must pass before you commit.
- Keep changes focused on the task you were given. Add or update tests for the behavior you change.
- Commit your work on the current branch with a short message that references the issue, e.g. `Add X (#3)`.
